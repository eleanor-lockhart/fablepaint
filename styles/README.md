# Styles

Each folder here is one style worked out on purpose, kept whole so it can be returned to.
What they share is in `../STYLE.md` (the house style); a style's own guide sits on top of that.

| style | what it is | state |
|---|---|---|
| [`lit-window/`](lit-window/) | colour woodblock prints of Pacific Northwest nights; flat pigments, one warm light | v3, three prints; git tag `lit-window-v3` |
| [`paperlight/`](paperlight/) | boxes of cut paper lit from behind and within, built at true size in Blender, photographed and animated on twos | v1, in progress |

## What a style folder holds

| | |
|---|---|
| `STYLE.md` | the guide: the idea, numbered rules with reasons, the method, a faults list, a changelog |
| `journal.md` | the evidence: what was read, measured and tried, and the critique of every picture |
| a kit | code for the style's own vocabulary of marks, on top of the shared tools |
| `subjects/` | things learned to draw from reference, each with a note on what memory got wrong |
| `refs/` | reference works and photographs, with sources and licences |
| `studies/` | small tests of one problem each |
| works | the finished pieces and the scripts that made them |

## How a style gets made (the loop that produced Lit Window)

1. Say what you can and cannot do, and pick a tradition that fits it.
2. Make one piece from memory before any research. Keep it as the baseline.
3. Read how practitioners work. Look at real examples and measure them.
4. Write the guide. Do studies. Make a piece. Measure it against the examples.
5. Critique the piece in the journal, fix it once, and change the guide.
6. Repeat from 4 with a different subject. Rules that survive three pieces are the style.
