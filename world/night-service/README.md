# NIGHT SERVICE

A shared world for the work in this repository: part animation project, part commonplace book.

| | |
|---|---|
| `BIBLE.md` | the premise, the seven rules, the cast, the things, the six episodes ("lamps"), what it is about |
| `LOG.md` | the Log of Local 9: the commonplace book. Scraps, lists, lines, pictures to make. Add to it; do not tidy it |
| `STYLE.md` | how the world looks on screen: the light code, staging rules, the faults list from the opening's review |
| `op/` | the opening: one minute with a theme, its storyboard, outside review (5/10), revision, cold reading and retrospective |
| `cast.py` | the cast as paper figures on the common rig (`backlot.figure`): build, head, costume, props, pose, window colour |
| `lineup.py`, `lineup.png` | key image 1: everyone, dark, one lit window each. No. 4 does not fit |

Design language: every figure is a dark paper shape with one lit window in its chest. Warm
for the night shift, warmest and brightest for the dead, a cold strip for Continuity, an eye and no
window for the Linemen. `STYLE.md` has the whole code.

Made with the tools here and nothing else: no generated images, no ready-made models.
