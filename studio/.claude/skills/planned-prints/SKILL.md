# Planned prints

The style, its rules, its method and its tools are written down in
`atelier/STYLE.md` (the `atelier` folder sits beside `studio` in the repository). Read that
file in full before drawing anything, and `studio/AGENTS.md` if you have not used the paint program.

Then do exactly what its **Method** section says, in order:

1. One sentence: hour, weather, the one light, the witness.
2. A notan sheet: three variants in three flat greys. Choose by the rule, not by drama.
   Read the faults list before printing.
3. A block list of nine pigments or fewer.
4. Construct: `camera()` box models for built things; measured landmarks from a gridded
   reference photograph for anything living. Never draw an animal, tree or vessel from memory.
5. Print, looking after every script.
6. Measure with `atelier/analyze.py` and compare with the ranges in the journal.
7. Write the critique into `atelier/journal.md`, revise once as a v2, and if you learned
   something general, change `STYLE.md` and add a changelog line.

The last step is what makes this a style and not a recipe: the guide is supposed to change
every time a picture teaches something.
