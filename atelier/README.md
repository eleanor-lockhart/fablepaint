# Atelier

One style, developed on purpose. Start with `STYLE.md`.

| | |
|---|---|
| `STYLE.md` | the style guide: rules, method, kit reference, faults list (version 3) |
| `journal.md` | the evidence: what was read, measured, tried, and what went wrong each time |
| `kit.py` | printmaking helpers on top of `../studio/studio.py` |
| `analyze.py` | measures a picture: value masses, chroma, warm share, detail; contact sheets |
| `subjects/` | things learned from reference: ferry, heron, lookout, orca |
| `refs/` | reference prints and photographs (`SOURCES.md` has licences), `fetch.py`, `gridref.py` |
| `studies/` | study 0 (from memory), materials sheet, memory-against-reference sheets |
| `prints/` | the finished prints (`p1`..`p3`, each `_v1` and `_v2`) and the scripts that made them |
| `compare/` | side-by-side sheets: memory vs reference, before vs after notes, assigned subject |
| `transfer/` | a cold-start agent's attempt to work from the notes alone |
